# sepcv — early performance diagnostics for rare-class active learning

Code for the paper

> F. Ros, E. Bertrand-Bonvillain, Y. Nasser. *Early performance diagnostics for rare-class
> active learning: when are they available, reliable, and worth their cost?* (submitted to
> Neurocomputing, 2026).

`sepcv` computes **SepCV** and **SepCV⁺**, cross-validated estimates of rare-versus-rest
separability on the labeled set of an active learner, and evaluates when they are available,
reliable and useful for allocating a shared annotation budget across rare-class tasks. The
repository runs every experiment of the paper and regenerates every report, table value and
figure. The data, the raw results and the reports are archived on Zenodo:
**DOI 10.5281/zenodo.23482224**.

## Installation

```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -e ".[test]"
pytest -q                     # about 1 min, synthetic fixtures
python -m sepcv smoke         # end-to-end synthetic run, a few minutes
```

Python ≥ 3.9. The paper was produced with Python 3.11; the exact package versions are listed in `requirements-lock.txt`.

## Reproducing the paper

Two routes, depending on whether you rerun the experiments.

**A. From the archived results (a few hours).** Download the `results_*.zip` files from Zenodo
and unpack them at the repository root (they create `results/`; the data are not needed for
this route). Then:

```bash
python reproduce.py analyse budget halving figures verify
```

**B. From scratch (several days on 8 cores).** Download only `data_*.zip`, then:

```bash
python reproduce.py all --n-jobs 8
```

Runs are resumable: one JSON file per (task, seed, start), so an interrupted run restarts
where it stopped. Every random number is derived by hashing (master seed, task, seed, start),
so runs are deterministic for a given software environment.

| Stage | What it does | Output |
|---|---|---|
| `run` | trajectories of the four experiments (`configs/*.json`) | `results/<experiment>/units/` |
| `reprobe` | probes at 78, 102 and 126 labels, recomputed from the stored acquisition order | `results/<experiment>/units_extra/` |
| `analyse` | association, forecasting, reliability, allocation, screening | `reports/{controlled,tabular,images}/` |
| `budget` | exploration-budget analysis | `reports/budget_{tabular,images}/` |
| `halving` | successive halving vs single-stage ranking | `reports/halving_{tabular,images}/` |
| `figures` | all figures of the paper and the graphical abstract | `paper_figures/` |
| `verify` | compares the reports with the numbers printed in the paper | console |

`PAPER_MAP.md` gives, for every table and figure of the paper, the report file it comes from.

Version 1.0.0 is the public release of the internal 3.x line used during the study; the
`run_manifest.json` of the archived results record the 3.x version that produced them. The
names `eswa_cache` (source kind) and `images_eswa_tasks` (experiment) refer to the companion
study whose prepared data are reused; they are kept so that the archived results stay readable
and resumable.

## Data

```
data/
├─ rare27/       27 imbalanced-learn datasets (.xlsx: feature_* columns + target_binary)
├─ cache/        prepared domain datasets (<id>.npz + manifest.json)
└─ embeddings/   cached image embeddings (<dataset>/<backbone>.npz with X, y)
```

The three folders are in the Zenodo deposit (`data_*.zip`), with the sources and licences of
each dataset in `tools/LICENSES_DATA.md`. One exception: the UNSW-NB15 data may not be
redistributed, so the four UNSW-NB15 tasks are absent from `data/cache/` (their results are
archived; to rerun them, download UNSW-NB15 from its source). Bank Account Fraud is in a
separate archive, `data_domain_baf.zip`, under CC BY-NC-SA 4.0. The synthetic tasks are
generated by `sepcv.synthetic` and need no data.

## Experiments

| Config | Tasks | Seeds × starts | Learners | Acquisition rules |
|---|---|---|---|---|
| `controlled` | 120 synthetic (3 geometries × 4 IR × 5 separations × 2 dimensions) | 5 × 2 | LR, RF, GBDT, k-NN | margin, random |
| `rare27` | 27 tabular | 10 × 2 | LR, RF, GBDT, k-NN | margin, random, most-likely-positive, core-set |
| `domains_v2` | 15 domain tasks (fraud, bankruptcy, maintenance, intrusion) | 10 × 2 | idem | idem |
| `images_eswa_tasks` | 42 one-vs-rest image tasks (15 datasets, 2 backbones) | 5 × 2 | idem | margin, random |

## Package layout

```
src/sepcv/
  engine.py       one unit = one (task, seed, start); all rules and learners share split and labels
  estimators.py   SepCV per base, held-out AP, complexity measures
  data.py         loading, IR-preserving subsampling, train-only imputation
  synthetic.py    controlled factorial
  reprobe.py      post-hoc probes from the stored acquisition order
  analysis/       load (SepCV⁺), diagnostic, forecast, reliability, decision, budget, halving,
                  ablation, controlled, report
scripts/          figures of the paper and verify_paper.py
tools/            make_zenodo.py (assembles the Zenodo deposit)
```
